# iGaming Mathematics & Probability Simulations

A couple of lightweight Python scripts designed to model applied probability, 
verify statistical convergence, and simulate core casino game mechanics. 

### Contents
* **`basic_3-reel_rtp.py`**: Simulates a classic 3-reel slot game to calculate Hit Frequency and Return to Player (RTP) profiles across 1,000,000 test cycles, including expected values.
* **`dice_convergence_tester.py`**: Simulates large-scale iterations (e.g. 1,000,000 rolls) of custom dice setups to observe sample outcome distributions.
